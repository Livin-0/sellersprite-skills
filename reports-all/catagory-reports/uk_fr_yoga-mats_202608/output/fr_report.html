04 · 四、若仍想试探的 3 个补充方向 / 3 Alternative Angles

本档位大类不建议直接立项，可从以下 3 个角度重新评估细分 / 蓝海 / 方向调整。

🔍 细分品类微创新（跳出父类）

策略：从大类跳出，找差异化细分：防滑 / 环保 / 加厚 / 旅行便携 / 孕妇 / 儿童 / 健身双面

方法：拉细分的 product node + market_research，看 CR10 是否 < 70%

达标线：若细分 CR10 < 70% 且 GMV > 200K，重跑评分可达 T2

🌊 蓝海长尾词缺口（Skill 27 思路）

策略：从 keyword_mine 筛 search>1500 且 titleDensity<30 的缺口词

方法：这些词代表有需求但产品未充分覆盖，可能是新 SKU 突破口

达标线：若命中 5+ 个缺口词 + 整词搜索增长 > 30%，可建独立变体

📈 重新评估方向 D1（强需求低供给）

策略：用 supply_demand_median 强判定：若 SD > 10，属 D1 蓝海方向

方法：D1 不受 CR10 否决线压制，相同 CR10 仍可进 T2

达标线：若 D1 命中，6 维打分权重重排，加权总分 ≥ 3.0 即可 T2
